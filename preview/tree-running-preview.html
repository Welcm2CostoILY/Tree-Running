Tree Running

Preview · sample data

A working preview of the RuneLite plugin. It starts from a sample account at 89 Farming with a small sample bank. Change crops in Settings, tick patches in the Run tab, or use the buttons in the game view to plant patches and move to the next day.

Simulate planting stands in for playing. In game the plugin ticks the exact patch you plant, in any order, with no clicking. Next day moves the clock 24 hours, so hardwood, redwood and Hespori come back when they've grown. Numbers use the same data and math as the plugin.
