Bank filter and crop labels: preview

Click Tree run under the bank, or tick Filter bank to this run in the panel, to show only what this run needs. Tick a patch to see the filter shrink when it's set to What's left.

The labels use the same colours as the "This run needs" box: green for trees, orange for fruit trees, and so on. Seeds, seedlings and saplings get the same label.

The Bank of Gielinor

Inventory

In game, the button is a right-click option on the bank's Show worn items button: Tree run filter. That's the same place Inventory Setups puts its "Filter Bank" option, so it doesn't need a new bank button. The filtered view is a hidden bank tag, so typing in the bank search or clicking another tab closes it like any other tag.

How it would work

  • Filter: uses RuneLite's own bank tag API, the way Inventory Setups does. The plugin registers a hidden "Tree run" tag whose items are worked out live from the run, so nothing is added to your saved bank tags.
  • Labels: drawn over the item, in the bank, inventory and seed vault. Names of 4 letters or fewer are shown whole. Longer names are cut to 4 letters, such as Iron, Calq, Papa and Cela.
  • Already in RuneLite: the built-in Item Identification plugin can label seeds and saplings too, at the bottom, in capitals. If you turn this on, turn off its seed and sapling options so you don't get two labels.
